# Homepage rebuild: the brief

Agreed 2026-09-11. Parked behind the funnel work, not cancelled.

## Why it has to happen

The homepage is now the front door of weareabundance.com, and it is selling a
business that no longer exists.

| Problem | Detail |
|---|---|
| **Sells a retired offer** | "Cohort 04" of the Selling System, four tiers (Launch $9K / Install $12K / Shift $1.5K/mo / Scale $3K/mo). None of that is the current offer |
| **Fabricated proof** | "we've installed it for 100+ businesses" and "$200M+ lifted". The case studies page says **five businesses, $11.3M**. The VSL says $11.5M. A 20x overstatement, live |
| **Fake urgency** | "Cohort 04 enrollment closes Friday at midnight ET, 2 install slots remaining" |
| **Wrong mechanism** | Built around "the Selling System" and its four pillars. The current mechanism is **Constraint-First AI Mapping** |
| **Prices on the page** | The assessment funnel is locked to no-price-anywhere. The homepage contradicts it |

Those numbers were placeholder copy from a fast build session. They were never
Ryan's claims. They still cannot stay on a live page.

## The brief

Make the homepage sell the same thing the funnel sells.

- **Headline: outcome-led.** The "how to X without Y" shape. This is the angle
  Ryan wanted and it does not fit the VSL gate page, whose headline has to mirror
  the video's disqualifier opening. The homepage is where it belongs.
- **Honest numbers only.** Five businesses, $11.3M, the reconciled Sep 2 set that
  already matches itsryanfrost.com. Nothing else.
- **No countdown, no fake scarcity.**
- **No price.** Same rule as the funnel.
- **One action:** the AI Growth Discovery Call.
- **Proof:** the five case studies, which are real and already written.
- Reads like a firm, not a course. That positioning is the reason the one-accent
  dark brand is worth keeping (see `BRAND.md`).

## The funnel rule this does NOT change

`/assessment` is a funnel. **It must never link back to the homepage**, however
good the homepage gets. Exits were removed 2026-09-12. Do not re-add a nav, a
logo link, or a footer menu to that page.

## Also still open

- **`selling-system.html`** is off-brand entirely: 53 distinct colours across five
  hue families, which is default Tailwind rather than BRAND.md. It also sells the
  retired 90-day install and its numbers contradict the homepage. Decide: retire
  it or rebuild it.
- **`/free`** still sells "Abundance Tribe, $97/mo", a retired tier.
- **`assets/js/nav.js`** still renders the whole dead ladder. The paths now 301 to
  the homepage, so the links are no longer broken, but the nav should lose them.
